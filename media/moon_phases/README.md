# 🌙 Images des phases / Moon phase images

## 🇫🇷 Français
Copier ces 8 PNG dans `config/www/moon_phases/` de Home Assistant (servies via `/local/moon_phases/<slug>.png`). Elles ne sont **pas** incluses dans le zip HACS.
